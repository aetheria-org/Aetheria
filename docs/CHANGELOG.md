# Aetheria 1.1.0 - 1.2.0

A feature-packed update introducing new trackers for farming and combat, chat enhancements, and dungeon helpers.

### New Features

* Added Ability Timer Overlay to track active item durations
* Added Damage Splashes with customization for crit/non-crit numbers and formatting
* Added Kill Combo Tracker with magic find and wisdom tracking
* Added Crush Alert to notify when Storm is near pillars in F7/M7
* Added Powder Mining Chat Filter to reduce chat clutter in Crystal Hollows
* Added Farming Tracker for crop value and coins/hour
* Added Organic Matter Tracker for farming
* Added Trevor Solver and Pelt Tracker with Trapper Warp helper
* Added Sensitivity Reducer for farming precision
* Added Emoji Support in chat with texture rendering and autocomplete
* Added Scrollable Tooltips for long item descriptions in Storage Overlay
* Added Global Chat for all SkyAtlas linked players.
* Added Diana Party System for a better mythological ritual experience.

### Bug Fixes & Improvements

* Added Garden related lines to Custom Scoreboard.
* Added levels to skyblockID in potions.
* Added multiple debug commands.
* Multiple improvements to the dungeon map.
